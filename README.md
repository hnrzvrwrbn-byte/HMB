# HMB Bites – Responsive Restaurant Website

A four-page responsive website built with HTML, CSS and JavaScript for a fictional Lagos restaurant (sample project for the New Horizon Web Development assignment).

**Live site:** _add your Netlify/Render URL here_
**Repository:** _add your GitHub URL here_

## Pages
- `index.html` – Home (welcome, introduction, navigation)
- `about.html` – About (history, mission, vision, values)
- `services.html` – Services (3 services, filter buttons)
- `contact.html` – Contact details and validated contact form

## Technologies
- **HTML5** semantic elements (`header`, `nav`, `main`, `section`, `article`, `footer`), forms, lists, images
- **CSS3** external stylesheet (`css/style.css`), box model, positioning, **Flexbox** (header, hero, footer), **Grid** (feature/service cards, about, contact layout), **media queries** at 900px and 700px
- **JavaScript** (`js/script.js`) variables, functions, events: mobile menu, services filter, back-to-top button, contact form validation

## Notes
The contact form validates in the browser only. No backend is connected, so messages are not sent. Contact details are sample data.

## Run locally
Open `index.html` in a browser. No build step needed.

## Deploy
Netlify: drag the project folder onto app.netlify.com/drop, or connect the GitHub repo (no build command, publish directory `/`).
